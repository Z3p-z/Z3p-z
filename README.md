## 👤 Über mich

Ich entwickle Discord-Bots und arbeite aktuell daran, meine Projekte komplett kostenlos auf einer 24/7-Plattform zu hosten – ohne auf Spenden angewiesen zu sein. 

Vielleicht wird es in Zukunft auch ein paar *Plus-Features* geben, um die Infrastruktur zu finanzieren. 😉

**🛠️ Tech Stack:**
`JavaScript` • `Node.js` • `Discord.js` • `Python`
